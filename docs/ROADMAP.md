# MathLab roadmap

## First release – equations and proportionality

- [x] Finnish-first home page and topic navigation
- [x] Short lesson notes for six learning areas
- [x] Multiple-choice practice with instant feedback and explanations
- [x] Local progress counters and completed-topic tracking
- [x] Responsive layout and keyboard-accessible native controls
- [ ] Dedicated end-of-round results screen
- [ ] More questions per topic and mixed difficulty selection
- [ ] Typed-answer exercises with algebraic answer checking
- [ ] Worked examples with step-by-step hints
- [ ] Progress details per topic and mistake review

## Later

- Interactive balance-scale model for equation transformations
- Visual proportionality tables and coordinate graphs
- Word-problem builder
- Finnish / English interface
- Optional export and import of local progress

## Product principles

- Teach the reasoning, not only the final answer.
- Explain why an answer is correct or incorrect.
- Keep tasks short and usable on phones and school computers.
- Store progress locally by default; no account is needed for the first release.
- Use original illustrations and exercises. Toporopa is a reference for interaction patterns, not a source to copy.
